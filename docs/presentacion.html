NotaLang

Un lenguaje para el cálculo de notas y promedios ponderados

Problemática y motivación

  • Cada ciclo calculamos promedios ponderados y «¿cuánto necesito en el final?» a mano o en Excel.
  • Errores frecuentes: pesos que no suman 100 %, notas fuera de 0–20, fórmulas mal copiadas.
  • Excel no conoce el dominio: una nota de 25 es «un número válido».
  • NotaLang: describir cursos de forma declarativa y que el compilador detecte esos errores.

Objetivos

  • Definir el léxico y especificarlo con expresiones regulares en ANTLR4.
  • Diseñar gramáticas libres de contexto no ambiguas y validarlas con derivaciones más a la izquierda.
  • Implementar tabla de símbolos con ámbitos y un analizador semántico (Visitor).
  • Verificar reglas del dominio: pesos = 100 %, notas en [0, 20], evaluaciones existentes.

Un programa en NotaLang

curso Compiladores {
    PC1 : 15% = 14;
    TP  : 20% = 16.5;
    PC2 : 15%;
    TF  : 25%;
    EB  : 25%;
}
var meta : decimal = 13;
mostrar("Promedio parcial: ", promedio(Compiladores));
mostrar("Necesito: ", necesito(Compiladores, meta));
Compiladores.PC2 = 12;
si (promedio(Compiladores) >= 10.5) { mostrar("Vas aprobando"); } sino { mostrar("Cuidado"); }

Analizador sintáctico (extracto de la GLC)

declCurso     → curso id { evaluaciones }
evaluaciones  → evaluacion evaluaciones | evaluacion
evaluacion    → id : porcentaje notaOpcional ;
notaOpcional  → = expr | ε

exprArit      → exprArit opSuma termino | termino
termino       → termino opMul factor | factor
siStmt        → si ( expr ) bloque sinoParte
sinoParte     → sino bloque | sino siStmt | ε
  • Un no-terminal por nivel de precedencia; llaves obligatorias ⇒ sin else colgante.
