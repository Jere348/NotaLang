NotaLang — Informe del Trabajo Parcial (Hito 1)

1.Problemática y motivación

Cada ciclo los estudiantes calculan su promedio en cursos con evaluaciones de distinto peso y necesitan saber cuánto les falta para aprobar. Normalmente esto se hace a mano o en una hoja de cálculo, lo que genera errores frecuentes: pesos que no suman 100 %, notas fuera del rango 0–20 o fórmulas mal copiadas. Una hoja de cálculo no detecta estos problemas porque no conoce las reglas de una evaluación académica.

NotaLang permite declarar cursos y evaluaciones de forma directa, registrar notas y obtener el promedio (promedio) o la nota necesaria (necesito). El compilador valida las reglas del dominio antes de ejecutar el programa.

2.Objetivos

General: implementar en ANTLR4 los analizadores léxico, sintáctico y semántico de NotaLang.

Específicos:

  • Definir el léxico del lenguaje e implementarlo con expresiones regulares.
  • Diseñar las gramáticas libres de contexto de cada construcción y validarlas con derivaciones más a la izquierda.
  • Implementar la tabla de símbolos y la verificación de tipos y reglas del dominio.
  • Probar cada analizador con entradas válidas e inválidas.

3.Construcciones del lenguaje

Tipos de dato: entero, decimal, texto, logico y curso. Funciones del dominio: promedio(C) y necesito(C, meta); C.E accede a la nota de la evaluación E del curso C.

ConstrucciónCinco ejemplos
C1 · Declaración de variables
var nota : decimal = 14.5;
var n : entero;
var nombre : texto = "Ana";
var aprobado : logico = verdadero;
var total : decimal = suma / n;
C2 · Asignación
x = 10;
prom = suma / n;

C3 · Expresiones
aritméticas, relacionales y lógicas

C4 · Sentencia selectiva
si (x > 3) { mostrar(x); }

si (p >= 10.5) { mostrar("A"); } sino si (p >= 8) { mostrar("S"); }

5.Analizador sintáctico

No-terminales en cursiva, terminales en negrita; ε es la cadena vacía y programa el símbolo inicial.

Programa
programa→sentencias EOF
sentencias→sentencia sentencias | ε
sentencia→declVar | asignacion | siStmt | mientrasStmt | paraStmt | leerStmt | mostrarStmt | declCurso | bloque
bloque→{ sentencias }
C1 · Declaración
declVar→var id : tipo inicializacion ;
tipo→entero | decimal | texto | logico
inicializacion→= expr | ε
C2 · Asignación
asignacion→destino = expr ;
destino→id | id . id
C3 · Expresiones
expr→expr o exprY | exprY
exprY→exprY y exprNo | exprNo
exprNo→no exprNo | exprRel
exprRel→exprArit opRel exprArit | exprArit
exprArit→exprArit opSuma termino | termino
termino→termino opMul factor | factor
factor→( expr ) | - factor | num_ent | num_dec | cadena | verdadero | falso | id | id . id | promedio ( id ) | necesito ( id , expr )
opRel→< | > | <= | >= | == | !=
opSuma→+ | -
opMul→* | / | mod
C4 · Selectiva
siStmt→si ( expr ) bloque sinoParte
sinoParte→sino bloque | sino siStmt | ε
C5 · Iterativas
mientrasStmt→mientras ( expr ) bloque
paraStmt→para id desde expr hasta expr bloque
C6 · Entrada y salida
leerStmt→leer ( destino ) ;
mostrarStmt→mostrar ( argumentos ) ;
argumentos→expr masArgumentos
masArgumentos→, expr masArgumentos | ε
C7 · Curso
declCurso→curso id { evaluaciones }
evaluaciones→evaluacion evaluaciones | evaluacion
evaluacion→id : porcentaje notaOpcional ;
notaOpcional→= expr | ε

Validación mediante derivaciones más a la izquierda

Cada gramática se validó con 4 derivaciones más a la izquierda (36 en total), incluidas en el Anexo A (docs/Anexo_Derivaciones.pdf). En C1, C2 y C4–C7, expr se abrevia con ⇒*, pues se valida en C3. Ejemplo:

Ejemplo (C7)curso Calculo { PC : 40% = 12; EF : 60%; }
  1. declCurso
  2. ⇒lmcurso id { evaluaciones }
  3. ⇒lmcurso id { evaluacion evaluaciones }
  4. ⇒lmcurso id { id : porcentaje notaOpcional ; evaluaciones }
  5. ⇒lmcurso id { id : porcentaje = expr ; evaluaciones }
  6. ⇒*lmcurso id { id : porcentaje = num_ent ; evaluaciones }
  7. ⇒lmcurso id { id : porcentaje = num_ent ; evaluacion }
  8. ⇒lmcurso id { id : porcentaje = num_ent ; id : porcentaje notaOpcional ; }
  9. ⇒lmcurso id { id : porcentaje = num_ent ; id : porcentaje ; }

6.Analizador semántico

Se implementó con un Visitor de ANTLR y una tabla de símbolos con ámbitos anidados (bloques y para), que guarda nombre, tipo, ámbito y línea de cada identificador. Errores verificados:

Cód.Error semánticoEjemplo que lo produce
E1Identificador (variable o curso) no declaradob = a + 1; sin declarar b
E2Identificador ya declarado en el mismo ámbito, o evaluación repetidavar x : entero; var x : decimal;
E3Tipos incompatibles en asignación (solo se admite entero → decimal)var edad : entero = 3.5;
E4Condición de si / mientras que no es logicosi (n) { … } con n entero
E5Los pesos de un curso no suman 100 %curso Q { PC1 : 30%; EF : 50%; }
E6Nota fuera del rango [0, 20]T1 : 50% = 25;
E7Evaluación inexistente o identificador que no es cursoIngles.ESCRITO = 15;
E8Operación con tipos incompatiblesvar r : decimal = "a" * 2;
